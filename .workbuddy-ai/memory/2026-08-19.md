# 2026-08-19

## okcode.es 官网重建（Next.js 静态站）

将旧的 Astro 5 + Starlight 项目重建为 **Next.js 15 (App Router) + React + TS** 的纯静态官网，保留 GitHub Pages 发布与 `public/CNAME`。

关键决策与坑：
- 路由用显式页面：`app/page.tsx`(英文根 `/`)、`app/es/page.tsx`、`app/zh-cn/page.tsx`，匹配 plan 要求的 `/（英文默认）、/es/、/zh-cn/`。
- `next.config.ts`: `output:'export'`, `trailingSlash:true`, `images.unoptimized:true`, `distDir:'out'`。无 basePath（自定义域名 okcode.es）。
- 三语文案全部集中在 `src/content/site-content.ts`（typed），组件只消费数据；示例案例/评价带 `placeholder:true` 并有界面提示。
- SEO：`src/lib/seo.ts` 生成 per-locale title/description/canonical/hreflang/OG；`app/sitemap.ts` 需 `export const dynamic='force-static'` 才能在 export 下生成。
- **坑**：本机 Node 被 `NODE_OPTIONS=--require=...genie-safe-delete.cjs` 注入了 safe-delete 包装，会在 `next build` 清理 `.next` 时抛错中断构建。解决：构建时用 `NODE_OPTIONS="" npm run build`。
- es/zh-cn 静态 HTML 的 `<html lang>` 暂为 `en`（根 layout 固定），由客户端 `LangSetter` 校正；hreflang/canonical/OG 均已正确。如需严格 SSR lang，可改 `[locale]` 动态根路由（但英文将变为 `/en/`）。
- 验证：`npm run build` 通过；`out/` 含 `/`、`/es/`、`/zh-cn/`、`sitemap.xml`、CNAME/robots/og/favicon；本地 http 服务三语均 200 且锚点齐全。

Workflow 已改为 setup-node@v4 + npm ci + next build + upload-pages-artifact(out) + deploy-pages@v4。
